# Portfolio Rendi Putra

Website portfolio pribadi Rendi Putra yang menampilkan project web development dan database.

Live: https://rendiputra04.github.io/portfolio/

## Teknologi

HTML, CSS, dan JavaScript (tanpa framework). Di-hosting dengan GitHub Pages.

## Struktur Folder

```
index.html   -> isi halaman
style.css    -> tampilan
script.js    -> animasi scroll, menu aktif, tahun footer
profile.jpg  -> foto profil
```

## Menjalankan Secara Lokal

Buka `index.html` langsung di browser, atau jalankan server sederhana:

```bash
python3 -m http.server 8000
```

Lalu buka http://localhost:8000

## Catatan Pengembangan

Cari kata `TODO` di `index.html` untuk melihat bagian yang masih bisa dilengkapi
(CV, pendidikan/pengalaman, studi kasus project, screenshot, link repo).
